Version: 2.0

Author: Aniket Paswan

1. Project Overview
1.1 Purpose

Develop a production-grade, full-stack portfolio platform that showcases technical expertise through an immersive user experience while demonstrating backend engineering skills.

The application shall provide:

Interactive frontend
Secure backend APIs
Analytics system
AI assistant
Contact management
Resume management
Project CMS
Blog system
Admin dashboard

The portfolio itself should serve as a demonstration of modern software engineering practices.

2. Objectives

The platform shall:

Create a memorable first impression.
Demonstrate backend architecture.
Showcase projects interactively.
Collect recruiter enquiries.
Track visitor analytics.
Provide an admin panel for content management.
Support future scalability.
